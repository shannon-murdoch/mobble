5. Jobs-to-be-done and feature coverage

Each feature earns points: N native = 1P paid tier, module or add-on = 0.8I integration = 0.6H partial = 0.5G gap = 0? not confirmable from public docs = 0 or 0.5 (toggle above)

How a job % is worked out: add up the points for the job's features and divide by the number of features. Every feature in a job counts equally. A job where every feature exists but sits on a paid tier scores 80%, and one where half the features are native and half are missing scores 50%. $ marks a job with at least one paid-tier feature and ⇄ one with at least one integration.
